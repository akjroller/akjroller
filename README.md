## 🚀 Featured Work

### 🎮 Diablo 4 Events Tracker (D4ET)

[**Diablo 4 Events Tracker**](https://discord.com/oauth2/authorize?client_id=1118297246379806781&permissions=2147568640&scope=bot%20applications.commands) is a completed Discord bot built for the Diablo 4 community.

D4ET provides real-time alerts for:

- World Bosses
- Helltides
- Gathering Legion events

It uses Discord slash commands and embedded alerts to help players keep track of important in-game events directly inside their Discord servers.

D4ET has been live on over **3,500 Discord servers**, serving more than **450,000 users**, and has delivered over **17.5 million alerts**.

### 🗺️ 50 States Challenge

A team gamification web app built for call center teams.

Agents mark states based on inbound caller locations, compete on leaderboards, and turn normal call volume into a friendly team engagement game.

This project combines:

- Team culture building
- Live leaderboards
- Admin tools
- Multi-team tracking
- Practical workplace gamification

### 📊 AUX 23 Reporting Tool

A Python reporting project designed to make Downtime AUX usage easier to review.

The goal is to take manually pulled Nextiva reports and turn them into cleaner weekly summaries by agent and Team Lead.

This project focuses on:

- Reducing manual spreadsheet work
- Improving reporting consistency
- Supporting coaching conversations
- Creating better operational visibility

## 💡 How I Think About Projects
